# 浮点的数值分析

## 前言
计算机的存储方式是二进制，且浮点数的表示位数有限，浮点数的计算和表示存在运算累积与「大数吃小数」等现象，所以这篇文章用于介绍浮点的数值分析，说明浮点数精度存在的问题，与常见缓解方法，但本文不会太多进行数学推导，主要给出现象、方法。

## 一些例子

下面给出计算机浮点误差的经典例子，
```python
# /usr/bin/python3
print(0.1 + 0.2)
# 0.30000000000000004
```

这在浮点计算中难以避免。所以，我们更多关心浮点累加顺序对精度的影响，下面就是一个调整计算顺序来避免「大数吃小数」的例子。

```python
# /usr/bin/python3
print(1e16 + 1 + (-1e16))
# 0.0

print(1e16 + (-1e16) + 1)
# 1.0
```

## 问题的根源

### 浮点表示的稀疏、不均

IEEE-754 binary 64 浮点标准表示是稀疏、不均匀的。

相邻两数间隔大小有 ulp(x) = 2^e−52^，其中 2^e^ ≤ |x| < 2^e+1^，单位舍入u = 2⁻⁵³ ≈ 1.11×10⁻¹⁶。

float(a op b) = (a op b)(1+δ)，　|δ| ≤ u，　op ∈ {+, −, ×, /}。

### 浮点加法误差

浮点加法顺序为：
1. 对阶，阶码（指数）较小的数，尾数右移至阶码对齐。
2. 相加
3. 舍入

小数常在对阶那一步被右移至尾数范围，而导致「大数吃小数」。

```python
# /usr/bin/python3
print(1+1+1e16)
# 1.0000000000000002e+16

print(1e16+1+1)
# 1e+16
```

类似的，我们把异号相加导致的精度损失称为相消。

吸收（对阶丢低位，与量级差有关）与相消（结果远小于各项，误差被相对放大）。

吸收可以通过排序缓解，相消本身不会增加绝对误差，但由于相消结果比原两个数小，所以相对误差会放大。

条件数，可以用来估计相对误差的大小。

|ŝ − s| ≤ γ^^n−1^^ · Σ^^i^^|x^^i^^|
相对误差：　|ŝ − s| / |s| ≤ γ^^n−1^^ · cond(s)
其中 cond(s) = Σ|x^^i^^| / |Σx^^i^^| ≥ 1。

## 方法

求和过程可以看成一棵树，顺序求和是退化为链表。

### 重排

原理：让中间部分和尽可能小。

按 |x| 升序相加。先把小的互相加，聚成较大的块，再与更大的合并，能最大限度保留低位。

升序优于降序，但并不最优；最小化 Σ|中间和| 是 NP-hard。

### 改变结构

1. 二叉树，O(log n·u)
2. 级联，把输入切成 w 段各自累加，再合并 w 个部分和。向量化友好。
3. 硬件多输入加法器，一次吃 k 个加数，直接压缩树深。
