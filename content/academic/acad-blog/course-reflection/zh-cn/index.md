# 课程概览 {#course-overview}

**课程：** TODO：课程名称\
**时间：** TODO：学期或学习周期\
**材料：** TODO：课程主页、教学大纲与主要参考资料

简要说明选择这门课程的原因，以及它与当前学习或研究问题的关系。

# 学习目标 {#learning-objectives}

列出课程开始时希望获得的知识、方法或实践能力。目标应尽量具体，方便在课程结束后回顾。

## 核心概念 {#core-concepts}

选择两到三个关键概念，用自己的语言说明它们之间的关系，并为定义、定理、案例或史料提供准确来源。

# 学习过程 {#learning-process}

## 作业、阅读与讨论 {#assignments-readings-and-discussion}

可以按主题而非时间顺序整理材料：

- 哪项作业最能检验对概念的理解；
- 哪篇阅读改变了原有看法；
- 哪次讨论暴露了定义或推理中的空缺；
- 哪种学习方法最有效，哪些方法需要调整。

### 不进入侧栏的补充记录

三级标题适合保留具体例子或补充材料，同时不会增加侧栏目录的长度。

# 收获与反思 {#outcomes-and-reflection}

## 已经掌握的内容 {#what-i-learned}

结合具体任务说明目前能够解释、比较或完成什么，避免只用“了解了”概括学习成果。

## 仍需厘清的问题 {#open-questions}

记录尚未解决的问题，并区分概念理解不足、证据不足，以及需要更多实践才能判断的部分。

# 下一步 {#next-steps}

- [ ] 重读一项关键材料并补充引用；
- [ ] 将一个概念用于新的案例或小型项目；
- [ ] 整理可以公开共享的课程笔记；
- [ ] 在设定日期后再次检查学习目标。
